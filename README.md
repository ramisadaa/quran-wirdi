# وِردي وميقات

تطبيق ويب عربي للجوال، مكوّن من أربع صفحات رئيسية:

1. **اليوم:** عدّاد للحفظ، اختيار الصلاة، ملخص منفصل لعدّادي القراءة والحفظ، وتقدّم الورد.
2. **القرآن:** شاشة قراءة هادئة للآيات فقط، مع تكبير وتصغير الخط وتعديل الورد، وزر مستقل لتسجيل تكرارات القراءة.
3. **التسميع:** حالة التسميع وعدّاد الأخطاء ومتابعة التفسير وتصفير عدّاد الصلاة المختارة وسجل الأيام.
4. **ميقات:** التطبيق الأصلي بكامل أقسامه (التاريخ الهجري، الصلاة، العملات، الطقس، الأدعية والإعدادات) مضمّن في صفحة مستقلة.

## التخزين والعمل دون اتصال

- وِرد القرآن، اختيار الصلاة، عدّادا القراءة والحفظ، سجل الأيام، التسميع، التفسير وحجم النص محفوظة في `localStorage`.
- من الإعدادات يمكن تنزيل أو مشاركة نسخة JSON للسجل واستعادتها لاحقًا، أو مسح سجل القرآن والبدء من جديد. مسح السجل لا يغيّر بيانات ميقات أو إعدادات وِردي.
- نص القرآن ثابت في `data/quran-uthmani.xml`، ولا يعتمد على API لعرض الآيات.
- مواقيت الصلاة والحساب التلقائي محليان بمكتبة Adhan المضمّنة؛ عند حفظ موقع وطريقة حساب في ميقات، يستخدم التطبيق بياناتهما لتحديد الصلاة الحالية وبداية اليوم عند الفجر. إذا لم يُحفظ موقع، يستخدم وقت الفجر اليدوي في الإعدادات.
- صفحة ميقات محتفظة بوظائفها الأصلية، ومنها الخدمات التي تحتاج الإنترنت مثل البحث عن المدينة والطقس والعملات. تخزين ميقات المحلي يبقى منفصلًا عن سجل الورد.
- عند نشر المشروع على HTTPS، يخزّن Service Worker ملفات التطبيق ومصحف القرآن محليًا بعد أول تحميل. قد تتطلب الخدمات الشبكية في ميقات اتصالًا بالإنترنت.

## التشغيل

افتح مجلد المشروع في VS Code وشغّل `index.html` عبر إضافة مثل **Live Server**. لا تفتح الملف بالنقر المزدوج (`file://`) لأن المتصفح يمنع JavaScript من قراءة XML بهذه الطريقة.

في صفحة ميقات، احفظ المدينة أو الموقع وطريقة حساب الصلاة. بعدها يمكنك تفعيل «تحديد الصلاة تلقائيًا حسب مواقيت ميقات» من صفحة اليوم. يبقى اختيار الصلاة اليدوي متاحًا أيضًا. طرق الحساب المضمّنة حاليًا هي رابطة العالم الإسلامي، وأم القرى، والهيئة المصرية؛ والعصر مضبوط على الشافعي كما في نسخة ميقات المرفقة.
