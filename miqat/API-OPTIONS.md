# مصادر البيانات ومسارات الاتصال

| الوظيفة | المصدر | وقت الاتصال |
| --- | --- | --- |
| الصلاة | Adhan 4.4.6 محلي، MIT | دون شبكة |
| التاريخ والقمر | Intl والحساب المحلي | دون شبكة |
| أسماء المدن | Open-Meteo / GeoNames | بحث المستخدم فقط |
| الطقس | Open-Meteo | الموقع المختار، مع مخزن 10 دقائق |
| العملة المشتركة | exchangerate.host عبر GitHub Actions | 3 فترات يوميًا |
| التحديث الشخصي | Currency API، إصدار يوم مثبت ومرآة | ضغط «تحديث الآن» فقط |
| الأدعية | data/duas.json | من الموقع أو نسخته المحفوظة دون اتصال |

لا يوجد AlAdhan في هذه النسخة. حفظ الموقع لا ينتظر أي مستهلك. GPS لا يحدد المنطقة الزمنية من الإحداثيات وحده؛ راجع حقل المنطقة الزمنية عند استخدامه، خصوصًا عند السفر.

المتصفح لا يتصل بـ `api.exchangerate.host` مطلقًا. المسار المدفوع أو المحدود بالحصة داخل مهمة GitHub، والمفتاح Secret لا يدخل الموقع. التحديث المجاني مستقل ولا يكتب ملف اللقطة المشتركة. التساوي في التاريخ يبقي لقطة الحساب؛ الأقدم لا يُعرض، والانحراف فوق 20% مرفوض. يعرض الكرت وقت الجلب بمنطقة المستخدم المختارة أو منطقة الجهاز، ويُخفي صف العملة الأساسية.

ملف أسعار الموقع يحتوي `latest` وآخر 21 نتيجة ناجحة. الحصة تُسجل في المستودع قبل الطلب، مع حفظ الفترة الأصلية ويوم التنفيذ الفعلي. مهلة أو فشل الطلب يحجز المحاولة دون إعادة تلقائية. السعر السابق لا يُمس عند خطأ. توجد نسخة استعادة من النتيجة في Actions إن فشل الدفع. الأداة ترفض القيم غير المعقولة والانحرافات الكبيرة؛ ينبغي مراجعة مصدر الأسعار إذا حدث تغيير اقتصادي حقيقي تجاوز الحد بدل تجاوز الفحص تلقائيًا.

يُنشر من مجلد data ملفا `duas.json` و`exchange-rates.json` فقط؛ لا يُنشر سجل الحصة أو جدولها أو أدوات التحديث أو الاختبارات.

المصادر الرسمية:

- [Adhan JS](https://github.com/batoulapps/adhan-js) و[طرق الحساب](https://github.com/batoulapps/adhan-js/blob/develop/METHODS.md).
- [Open-Meteo Weather](https://open-meteo.com/en/docs) و[Geocoding](https://open-meteo.com/en/docs/geocoding-api) و[الشروط](https://open-meteo.com/en/terms).
- [خطة exchangerate.host](https://exchangerate.host/pricing): الخطة المجانية المعلنة 100 طلب/شهر، تحديث يومي، وغير تجارية. ثلاث محاولات لا تعني تغير السعر ثلاث مرات.
- [Currency API](https://github.com/fawazahmed0/exchange-api): بيانات يومية دون مفتاح. العناوين مثبتة بتاريخ يوم UTC، وليست `@latest`.
- [جدولة GitHub](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule): تدعم IANA timezone، وقد تتأخر أو تُفقد مهمة، وتخضع لتعطيل الخمول. راقب أول تشغيل فعلي؛ لا ندّعي تشغيلًا في حسابك قبل تفعيله.

الإسناد وروابط المصادر معروضة داخل الكروت، وترخيصا الخطين ومكتبة Adhan مرفقان. لا تمثل البادئة في Local Storage حماية من XSS في مشروع آخر تحت الأصل نفسه.
