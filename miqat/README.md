# لوحة يومك — النسخة المراجعة

خمسة كروت عربية RTL بالهوية نفسها، أسفل بعضها على جميع الشاشات: التاريخ، الصلاة، العملات، الطقس، والأدعية. الأخضر والأزرق والعنابي، وخطّا نوتو العربي والقاهرة محليان بصيغة WOFF2.

## التشغيل المحلي

افتح `index.html` عبر Live Server، أو شغّل `start.bat` على Windows عند وجود Python، أو `python3 run_local.py`. العنوان `http://127.0.0.1:8787/index.html`. اترك نافذة الخادم مفتوحة. فتح الملف بالنقر المزدوج عبر `file://` يمنع بعض وظائف JSON وPWA.

لا يحتاج الزائر إلى Python أو Node. هذه الأدوات للتشغيل المحلي والاختبارات ومهمة GitHub فقط.

## الموقع والصلاة والتاريخ

- **الموقع مستقل:** نموذج واحد في الإعدادات. نجاح البحث يحفظ الموقع فورًا، ثم يُخطر الصلاة والطقس والتاريخ؛ فشل أحدها لا يمنع الباقي. يوجد زر «اختيار المدينة» ظاهر عند أول استخدام.
- اختر المدينة والدولة، أو GPS الاختياري، أو أدخل الإحداثيات والمنطقة الزمنية يدويًا. المنطقة الزمنية المستلمة من البحث تُستخدم للمدينة؛ GPS والإحداثيات اليدوية يستخدمان الحقل القابل للتعديل. راجعه إذا اختلف عن موقعك الفعلي.
- **الصلاة بلا API:** الحساب محلي بمكتبة Adhan 4.4.6 المضمّنة بترخيص MIT. الطرق الثلاث في قائمة مركزية، والعصر شافعي. أم القرى يضبط العشاء إلى 120 دقيقة في رمضان، وتوجد معالجة مكتبة Adhan لخطوط العرض العالية. راجع مواقيت الجهة المحلية قبل الاعتماد التعبدي عليها.
- تُحفظ 31 يومًا محسوبة. عند تجاوزها يعيد التطبيق الحساب محليًا دون شبكة؛ لا تنتهي صلاحية وظيفة الصلاة بعد يومين. الضغط على الكرت يفتح جميع المواقيت.
- التاريخ الهجري أم القرى مع تعديل ± يومين؛ يمكن اختيار تبديل اليوم الهجري عند المغرب حسب الموقع المحفوظ. دون موقع صالح يبقى اليوم المدني مع تنبيه. الميلادي بأسماء `ar-PS` مثل «تشرين الثاني». شكل القمر تقديري وليس تقرير رؤية فلكية.

## العملات: الشرطان ثابتان

1. **التحديث المركزي من حسابك ثلاث مرات يوميًا** عند 08:15 و13:15 و18:15 بتوقيت فلسطين `Asia/Hebron`. تحفظ المهمة النتائج في `data/exchange-rates.json` وتنشرها لجميع الزوار.
2. **الخدمة المجانية عند ضغط «تحديث الآن» فقط.** نتيجة شخصية مؤقتة لهذا العرض، دون استدعاء حسابك أو تعديل ملف الموقع أو نسخته في Local Storage.

المتصفح لا يحتوي مفتاح حسابك ولا يستدعي API الحساب. عدد الزوار وضغطهم الزر لا يغير حصة الحساب. الحد المعتاد 3 × 31 = **93 محاولة في أطول شهر**، مع منع تكرار الفترة وحد يومي 3 وحد شهري 100.

التحديث الشخصي يستخدم إصدار يوم UTC مثبتًا من Currency API بدل `@latest`، ثم مرآة مجانية إذا لزم. لا تُستبدل الأسعار الأساسية إذا تساوى تاريخ المصدرين أو كان المجاني أقدم؛ تظهر رسالة «لا توجد بيانات أحدث». تُرفض القيم الناقصة وغير المعقولة والانحرافات التي تتجاوز 20% لأي زوج مقارنة باللقطة المشتركة. تُميّز الواجهة بين عدم نشر نسخة اليوم وفشل الاتصال والاستجابة غير الصالحة. عند الفشل تبقى البيانات الأساسية. عند اختيار عملة المقارنة يُخفى صف العملة نفسها.

الأسعار مرجعية، والخدمات ذات تحديث يومي قد تعيد القيم نفسها في الفترات الثلاث. توجد لقطة أولية بتاريخ **2026-11-04** من Currency API إلى أن تفعل حسابك؛ يظهر المصدر الحقيقي دائمًا.

## تفعيل GitHub Pages والجدولة

**لم تُفعّل جدولة في حسابك ولم يُختبر مفتاحك الحقيقي ضمن تجهيز هذا الملف.**

1. ارفع جميع محتويات هذا المجلد، بما فيها `.github`، إلى الفرع الافتراضي `main` أو `master`.
2. أضف Secret من **Settings → Secrets and variables → Actions** باسم `EXCHANGERATE_API_KEY` وقيمته مفتاح حسابك. لا تكتبه في أي ملف عام.
3. من **Settings → Pages → Source** اختر **GitHub Actions**. اسمح بكتابة البوت إلى الفرع إن منعتها سياسة المستودع أو حماية الفرع. الصلاحيات مقسمة حسب وظيفة كل job؛ مهمة النشر لا تملك كتابة المحتوى، ومهمة الأسعار لا تملك نشر Pages.
4. قبل أول تشغيل، اضبط `usageAlreadyConsumed` و`usageMonth` في `data/exchange-schedule.json` إذا استهلكت من الحساب مسبقًا. الافتراضي صفر لشهر `2026-11`.
5. من **Actions → Update shared rates and deploy dashboard → Run workflow** نفّذ أول تشغيل. ستمر الاختبارات، ثم الجلب إذا لم تكن الفترة محجوزة، ثم النشر. يُحتسب التشغيل اليدوي ضمن إحدى الفترات الثلاث.

النشر على push لا يجلب من حسابك. تعديل التوقيت يحتاج تغيير `times` و`timezone` في JSON، **والـ cron المنفصل لكل فترة والمنطقة الزمنية** في workflow. تغيير الفرع الافتراضي عن main/master يحتاج تعديل قائمة `push.branches`.

تحجز المهمة الفترة وتحفظ الحجز في GitHub قبل الاتصال بالمزوّد. لا تحذف `data/exchange-update-state.json` ولا تصفّره. تعتمد الفترة على cron الصريح ووقت إنشاء التشغيل الأصلي، بما فيه إعادة التشغيل، وليس «آخر موعد مضى» عند التنفيذ. تُرفض المهام الأقدم من 18 ساعة بدل استهلاك حصة يوم جديد بالخطأ، وتُحسب الحدود حسب يوم وشهر الاتصال الفعلي.

بعد الجلب تُحفظ نسخة استعادة كـ artifact لمدة 7 أيام قبل محاولة push. تُعاد محاولة الدفع مع fetch/rebase دون طلب API جديد. إذا تعارض تعديل نفس ملفات البيانات يتوقف الدفع، وتبقى نسخة الاستعادة في Actions؛ استعدها بدل إعادة استهلاك الحساب. إذا اندمج تعديل كود جديد بعد CI، يمنع النشر حتى يختبره تشغيل الرفع الأحدث، مع الاحتفاظ بنتيجة الأسعار. انقطاع الخدمة يحتسب محاولة الفترة احتياطًا ويحافظ على آخر أسعار سليمة.

GitHub قد يؤخر أو يفوّت موعدًا؛ الجدولة ليست ضمانًا بالدقيقة. افحص الوقت الفعلي لأول تشغيل وتبويب Actions لاحقًا. قد تُعطّل المهام في مستودع عام بعد 60 يومًا دون نشاط؛ لا نعتمد على أن commit البوت يمنع ذلك. لا تستخدم نفس المفتاح في مهام مستقلة إضافية دون احتساب استهلاكها.

## الأدعية والتخصيص

`data/duas.json` هو مصدر 15 دعاءً. عدّله في مكانه ثم حدّث الصفحة؛ بعد النشر ارفع التعديل. لكل دعاء `id` ثابت فريد و`text` و`reference` و`sourceUrl` من HTTPS. المرجع رابط ظاهر في الكرت. النص الطويل يتوسع عند الضغط، والافتراضي مختصر.

في كل فتح يُختار دعاء غير مقروء. Local Storage يحفظ معرّفات المقروء وآخر اختيار فقط. تُعاد الدورة بعد اكتمالها دون تكرار فوري، ولا تُحتسب البطاقة المخفية. يمكن إعادة الدورة من الإعدادات.

روابط المالك في `config.js`؛ الرابط المعروف GitHub هو `https://github.com/ramisadaa`، والبقية مخفية إلى أن تضيف روابطك. تخصيص المستخدم المحلي للروابط لا يغير روابط جميع الزوار.

جميع مفاتيح التخزين تبدأ بـ `dailyDashboard.`. لا نستورد مفاتيح `themeColor` أو `themeFont` أو `prayerLocation` أو `prayerDays` العامة؛ قد تحتاج اختيار المظهر مجددًا إن استعملت نسخة قديمة. البادئة تمنع التضارب العرضي، لكنها ليست عزلًا أمنيًا بين مواقع GitHub Pages التي تشترك في الأصل نفسه.

## العمل دون اتصال والخصوصية

بعد الزيارة الأولى الناجحة عبر HTTPS أو localhost، يحفظ Service Worker ملفات التطبيق والخطوط والأيقونات وملفي JSON العامين. يمكن فتحه دون اتصال: التاريخ والصلاة والأدعية محلية، والعملة والطقس يعرضان آخر نسخة مع تاريخها. المدينة الجديدة والبيانات الحية تحتاج اتصالًا. تحديث JSON عند وجود شبكة يحدّث مصدر الأدعية؛ النسخة غير المتصلة هي آخر ملف محمّل، وليست نصوصًا بديلة في Local Storage.

توضح الإعدادات والتذييل ما يُرسل: اسم المدينة للبحث في Open-Meteo، والإحداثيات للطقس، واتصال Currency API عند التحديث الشخصي دون موقعك. الصلاة لا ترسل أي إحداثيات إلى خدمة خارجية. راجع شروط Open-Meteo وخطة العملات عند الاستخدام التجاري. CSP تمنع السكربت الخارجي وتسمح بالاتصالات المحددة؛ `style-src` يسمح بالتنسيقات الديناميكية اللازمة للألوان والأحجام. منع iframe يحتاج ترويسات استضافة؛ لا يعمل `frame-ancestors` من meta على Pages.

## الملفات والاختبارات

CSS منفصل: `backgrounds.css` للخلفيات، `cards.css` للكروت، `settings.css` للإعدادات، و`style.css` للتخطيط والخطوط. `app-core.js` يوحّد التخزين والشبكة وسجل الأحداث، و`location.js` خدمة الموقع، والباقي مستهلكون مستقلون.

اختبارات المنطق لا تستخدم الشبكة أو مفتاحك. يتطلب التحقق Node وPython 3.10+ وبيانات IANA للمنطقة الزمنية. وثّقت النتائج والقيود في `VALIDATION.md` والإصلاحات في `REVIEW.md`.

```bash
python3 -m pip install -r requirements-tests.txt
python3 tools/check_project.py
node tests/test_core.cjs
node tests/test_currency.cjs
node tests/test_ui.cjs
node tests/test_sw.cjs
python3 tests/test_exchange_job.py
python3 tests/test_git_publish.py
python3 -m playwright install chromium
python3 tests/test_visual.py
```

CI يشغّل الفحوص قبل النشر، ويولّد 9 لقطات لثلاثة ألوان × ثلاثة عروض (320 و390 و1440)، ويختبر التباين والتخطيط والكيبورد وفتح الصفحة دون اتصال. تنفّذ pushes الفرعين الأساسيين CI عبر workflow النشر، وبقية الفروع وPR عبر `ci.yml`.

لبناء ملفات عامة دون سجل الحصة والأدوات: `python3 tools/build_site.py --output public`؛ مجلد الإخراج يجب أن يكون فارغًا. البناء يولّد قائمة PWA ورقم نسختها من المحتوى تلقائيًا. عند تعديل المصدر والتشغيل المحلي نفّذ `python3 tools/prepare_pwa.py` لتحديث نسخة العمل دون اتصال. ملفات المصدر وتراخيص الطرف الثالث مرفقة بالكامل.
